## 決策分級建議（依三問結果）
- **影響小 + 可逆 + 隱性脈絡低** → 快速決定，邊做邊修。
- **影響大 或 不可逆** → 放慢、先做小規模驗證。
- **隱性脈絡高** → 先找握有脈絡的人對話，再決定。
